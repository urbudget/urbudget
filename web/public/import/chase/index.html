How to download Chase transactions

In Spending Planner on chase.com you can download this year's and last year's checking and credit card transactions as a spreadsheet (CSV) or as a Quicken, QuickBooks or Microsoft Money file. The Chase Mobile app only gives you a PDF. Here's where the download is, which file to pick, and how to bring it into UrBudget.

What Chase lets you download

  • Four file types, on a computer. Chase lists a spreadsheet (CSV), Quicken Web Connect (QFX), Quicken or Microsoft Money (QIF), and QuickBooks Web Connect (QBO).
  • This year and last year. That's what Chase says Spending Planner's download covers on a computer. Other download screens on chase.com may offer a different range.
  • Checking accounts and credit cards. Chase documents the download in Spending Planner, its spending tool for Chase checking and credit card customers.
  • Only a PDF in the app. The Chase Mobile app downloads a PDF of last calendar year's transactions. That's useful at tax time, but no budgeting app can import a PDF.

Download your transactions from chase.com

Chase's help pages describe the download inside Spending Planner on chase.com. Use a browser on a computer.

  1. Sign in at chase.com. Skip the Chase Mobile app for this; its download is a PDF.
  2. Open Spending Planner. Chase puts it in the Manage Your Spending Plan section of the Plan, Track, or Manage dashboard.
  3. Scroll down the Spending Summary tab. Spending Planner opens on Spending Summary. Below your spending by category are the download options, which cover this year and last year.
  4. Save a Quicken Web Connect (QFX) file. Choose the QFX format and save the file. If Chase asks which account, pick one: UrBudget imports each file into a single account, so download your checking and your card separately.

Which format to pick for UrBudget

Chase's formatIn UrBudget
Quicken Web Connect (QFX)The one to pick. Money out is negative and money in is positive, on your checking account and your card alike. Each transaction carries Chase's own ID, so a file that overlaps your last one doesn't add anything twice.
Spreadsheet (CSV)Imports only if its columns are ones UrBudget reads. Chase doesn't publish its CSV layout, so if you use it, look at the preview: a purchase has to show as money out.
Quicken or Microsoft Money (QIF)Imports, but without transaction IDs. UrBudget spots repeats by date, payee and amount instead, and you set the date order yourself.
QuickBooks Web Connect (QBO)Not supported. UrBudget doesn't open .qbo files.

Import it into UrBudget

  1. Open the matching account. In UrBudget, select the account the file is for, such as your Chase checking or your Chase card, and choose Import file above its transactions.
  2. Add the file. Choose Choose a file and pick the .qfx you saved, or drag it onto the box. UrBudget reads the format from the file name.
  3. Preview it. Choose Preview transactions. A QFX file needs no date order. If you went with CSV or QIF, set Dates in the file to Month/day/year before you preview.
  4. Review the rows. Rows from an earlier import are marked as already imported and skipped. A row with the same amount as a transaction you typed in within 10 days is offered as a match, so you don't end up with both. Any row with more than one possible match needs your choice.
  5. Import. Choose the import button, which shows how many transactions will come in. They wait in the register for your approval.

If something looks wrong

  • Today's card purchase isn't in the file. Chase says Spending Planner's budget is built from posted transactions, so a purchase that's still pending may not be there yet. It will be in your next download, and the rows you already have are skipped.
  • Checking and card transactions are mixed together. Every row in a file goes into the account you're importing into. If the preview shows more than one account's transactions, cancel and download each account on its own.
  • You need older transactions. Spending Planner's download goes back to the start of last year. Older months are in your PDF statements, which can't be imported. If you start your budget from today's balances, you don't need them.
  • The only choice is a PDF. You're in the Chase Mobile app. Switch to chase.com on a computer.
  • Purchases show up as money coming in. That's a spreadsheet file writing purchases as positive amounts. Tick Purchases are positive (UrBudget 1.0.3 and later) and preview again, or import the QFX file instead.

Put your Chase file to work

UrBudget is free on Windows and macOS. It never asks for your Chase login.
