How to download Bank of America transactions

Bank of America stopped offering Quicken (QFX) files in 2025, so the file to download now is its spreadsheet file, a CSV. Here's how to get it from Online Banking, what to check in it, and how to import it into UrBudget.

What Bank of America offers now

  • No more QFX or OFX files. A Quicken notice dated September 30, 2025 says Bank of America discontinued all of its OFX services, including Web Connect (QFX) files. Quicken users now connect through Quicken's own link, which needs your bank login.
  • A spreadsheet download. Bank of America's help still lists downloading transactions for use with financial software in Online Banking. The spreadsheet format saves a .csv file, which is what you'll import.
  • Up to 12 months on credit cards. Bank of America's credit card help says you can request up to 12 months of detailed transaction information in Online Banking.

Download your transactions from Online Banking

Bank of America's help pages describe the download in Online Banking on a computer. They don't name every button for personal accounts, so the labels on your screen may differ a little from these steps.

  1. Sign in to Online Banking and select the account. Checking, savings or credit card. Each file holds one account.
  2. Choose Download. It's on the account's activity page, with the transactions.
  3. Pick the period. Cover the dates since your last download. An overlap does no harm.
  4. Choose the spreadsheet file type, then Download transactions. Save the .csv file somewhere you'll find it.

Check the CSV before you import it

With no QFX file, the CSV's layout decides how cleanly it imports. Bank of America doesn't publish its column layout, so let UrBudget's preview show you. UrBudget needs:

  • Column names on the first line: a date (Date, Transaction Date, Posted Date or Posting Date), a description (Payee, Description, Name or Merchant), and either Amount or separate Debit and Credit columns.
  • Money out as a negative amount, when there's a single Amount column. If yours are the other way round, tick Purchases are positive (UrBudget 1.0.3 and later).
  • Numbers it can read. Commas, minus signs and a $ sign are all fine in 1.0.3 and later.

If the preview complains, open the file in a text editor or spreadsheet and fix the one thing it points to:

  • Summary lines above the column names. Delete every line above the row of column names, so that row is the first line, and save as CSV.
  • A line with no amount, such as a balance line. Delete that row.
  • Purchases written as positive numbers. Tick Purchases are positive and preview again.

Import it into UrBudget

  1. Open the account. In UrBudget, select the account the file came from and choose Import file above its transactions.
  2. Add the .csv file. Choose Choose a file, or drag the file onto the box.
  3. Set the date order. US dates are month first, so set Dates in the file to Month/day/year, then choose Preview transactions.
  4. Look over every row. Check one purchase and one deposit or payment: purchases should be money out. Rows you imported before are marked as already imported and skipped, and rows that look like transactions you entered yourself (same amount, within 10 days) are offered as matches.
  5. Import. Choose the import button. The transactions land in the register, waiting for your approval.

If something looks wrong

  • UrBudget says the CSV needs Date, Payee and Amount headers. The first line of the file isn't the row of column names. Remove the lines above it and try again.
  • UrBudget can't read a date. Dates in the file is set to another order. Choose Month/day/year.
  • A transaction from last week comes in again. A CSV has no transaction IDs, so UrBudget recognizes repeats by date, payee and amount. If Bank of America changed a description since your last download, the row looks new. Set it to Skip.
  • Your card history stops after 12 months. That's as much detail as Bank of America's card help says you can request online. Older months are in your PDF statements; starting your budget from today's balance means you don't need them.
  • You were using QFX files before. Rows from those files and rows from the new CSV are recognized differently, so the first CSV that overlaps them can show repeats. Start the CSV the day after your last QFX file ended.
