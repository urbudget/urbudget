How to download U.S. Bank transactions

U.S. Bank online banking lets you download up to 18 months of transactions as a spreadsheet (CSV), Quicken (QFX) or QuickBooks (QBO) file. The mobile app doesn't, and older activity is on your statements. Here's where the download is, which file to pick for a budget, and how to bring a file or a statement into UrBudget.

What U.S. Bank lets you download

  • Three formats. Spreadsheet (.csv), Quicken (.qfx) and QuickBooks (.qbo).
  • Up to 18 months back. For anything older, U.S. Bank sends you to your statements.
  • In online banking only. U.S. Bank says transaction downloads aren't available in the U.S. Bank Mobile App, so use online banking in a web browser.
  • General online banking help. The download article doesn't list account types. U.S. Bank's Quicken page says its checking, savings and credit card accounts work with Quicken, the program the QFX file is made for. Neither page promises the download for every specialized account.
  • Transactions, not Money tracker. The spending summaries in U.S. Bank's Money tracker can't be downloaded. Download the transactions themselves.

Download your transactions from U.S. Bank

  1. Log in to online banking. Go to usbank.com in a web browser. The mobile app has no download.
  2. Select the account. Choose the account you want transactions from.
  3. Click the download icon. It's in the upper-right corner of the Transactions tile, above the list. U.S. Bank's Quicken page calls it Download Transactions.
  4. Choose the dates and the format. Set a date range, up to 18 months back, and pick Quicken (QFX) as the file format.
  5. Click Download. Your browser saves the file. U.S. Bank also offers Open file, which shows the file in the format you chose; you don't need it for importing.

Repeat this for each account. If you budget weekly, start the date range a few days before your last download: the overlap is recognized when you import, so nothing is added twice.

Which format to pick for your budget

Pick Quicken (QFX). It's a standard OFX file underneath, and two things make it the safest of the three:

  • Money out is always a negative amount and money in a positive one, so purchases, card payments and deposits land on the right side.
  • Each transaction carries U.S. Bank's own ID. When next week's file overlaps this one, UrBudget knows which rows it already has and skips them.

The QuickBooks (QBO) file is made for QuickBooks, and UrBudget doesn't open .qbo files. The spreadsheet (CSV) can work too: UrBudget needs a header row with a Date column, a payee column (Name or Description works) and an Amount column with money out as negative numbers. U.S. Bank's help pages don't list the CSV's columns, so if you use it, look closely at the preview before you import.

Import it into UrBudget

  1. Open the account. In UrBudget, select the account the file came from, such as your U.S. Bank checking, and choose Import file above its transactions.
  2. Choose the file. Click Choose a file, or drag the .qfx file onto the box. UrBudget picks the format from the file's extension.
  3. Check the date order. A QFX file's dates are in a fixed format, so there's nothing to set. For a CSV, set Dates in the file to Month/day/year if the dates look like 10/31/2026.
  4. Review the rows. Choose Preview transactions. Every row is listed before anything is saved. Rows you imported before are marked as already imported and skipped. A row with the same amount as a transaction you typed in within 10 days is paired with it; you can change that to add it as new.
  5. Import. Choose Import. The transactions appear in the register, waiting for your approval and a category.

Older than 18 months: use your statements

For activity older than 18 months, U.S. Bank's article points you to your account statements. A statement is a document, not a transaction file, so the file import can't read it. UrBudget's optional assistant can.

  1. Open the assistant. Click Assistant, or press Ctrl+J (⌘J on a Mac). The first time, it asks you to sign in with ChatGPT or add an API key in Settings.
  2. Attach the statement. Click the paperclip (Attach a file) or drop the PDF onto the assistant, and say where it goes, for example "Import this statement into U.S. Bank Checking."
  3. Read the card. The assistant replies with a card, such as 42 transactions ready to review, showing the dates, outflow and inflow. When the statement shows totals, the card says whether they match, and it reminds you to check the amounts it read.
  4. Choose Review import. The rows open in the same import preview as a file, with duplicates and matches marked. Nothing is added until you choose Import.

The assistant runs on your ChatGPT plan or your own OpenAI or Anthropic API key. Your message, the statement and the budget details it looks up go to that company. It never needs your bank login, so don't paste passwords or security codes into it. For the last 18 months, the QFX download is simpler and stays on your computer.

If something looks wrong

  • Nothing older than 18 months. That's U.S. Bank's limit for downloads; older activity is on your statements. A new budget doesn't need it: start from today's balance and import from here on. If you do want older months, have the assistant read the statements, as above.
  • A statement month overlaps a download. Rows already imported from the QFX file are offered as matches, because a statement's descriptions can differ from the file's. Choose the match instead of adding the row again.
  • Purchases show up as money coming in. The file's amounts aren't signed the way UrBudget expects, which can happen with a spreadsheet file. Cancel, download the Quicken (QFX) file instead, and import that.
  • UrBudget can't read a date. In a CSV, the date order starts at Year-month-day. Set Dates in the file to Month/day/year and preview again.
  • Every row says already imported. Those dates are in UrBudget from an earlier file. Nothing is added twice; download a range that starts after your last import if you want a shorter list.
