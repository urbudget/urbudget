Budget without linking your bank

You can budget without connecting your bank. Many banks let you download transactions as a file from their website. Here's which file to pick, with step-by-step guides for US banks, cards and PayPal.

Why import files instead of linking

A bank connection uses a data provider and the authorization method your bank supports. A password change, a new security step or a bank website update can interrupt it until you reconnect. File import is an alternative when you prefer to download transactions yourself.

A downloaded file has none of that. Nothing logs into your bank but you, the file holds exactly what the bank shows you, and it works the same way whichever bank you use. The cost is a minute or two every week or month to download the file and import it. Many people find that regular look at their transactions is worth having anyway.

Importing a file this way happens on your computer. UrBudget's optional assistant can also read a statement or receipt you drop into it, but that sends the document to the AI provider you chose (your ChatGPT plan, or your own OpenAI or Anthropic key). The file import doesn't need the assistant.

Prefer to connect? UrBudget 1.0.4 and later also supports SimpleFIN bank sync for supported US and Canadian institutions, with a separate SimpleFIN subscription. File import stays available, with no provider subscription.

Which file to download

FormatWhat it isFor budgeting
QFXQuicken's version of OFX. Banks often label it "Quicken" or "Quicken Web Connect".Usually the best choice when it's offered: amounts have the right sign, and each transaction carries the bank's own ID, so a file that overlaps the last one doesn't create duplicates.
OFXOpen Financial Exchange, the standard format. Sometimes labelled "Microsoft Money".Just as good as QFX. Pick whichever your bank offers.
CSVA plain spreadsheet file. Every bank lays its columns out differently.Works when the columns are clear, but some card issuers show purchases as positive numbers, which a budget reads as money coming in. Check the preview, or use QFX or OFX.
QIFQuicken's older format, with no transaction IDs.Fine if it's all your bank has. Re-importing the same dates needs more care.
QBOThe same structure as OFX, made for QuickBooks.Meant for accounting software; choose QFX or OFX instead.

Importing the file into UrBudget

  1. Open the account. Select the account in the sidebar and choose Import file above its transactions.
  2. Pick the file. Drop in the CSV, OFX, QFX or QIF file. For a CSV or QIF, choose the date order your bank uses (month/day/year in the US).
  3. Review the rows. UrBudget shows every row before anything is saved. Rows you've already imported are marked as duplicates and skipped, and rows that look like ones you typed in yourself (same amount, within 10 days) are offered as matches, so nothing is counted twice.
  4. Import. The new transactions land in the account, ready to categorize.

A CSV needs a header row with Date, Payee (or Description) and either Amount (negative for money out) or Outflow and Inflow (or Debit and Credit). Currency signs and decimal commas are fine. If a card's CSV shows purchases as positive numbers, tick Purchases are positive when you import it (UrBudget 1.0.3 and later). If the CSV still doesn't fit, download the bank's QFX or OFX file instead, or save UrBudget's CSV template and paste your rows into it.

A routine that keeps up

Pick a day, such as Sunday morning or the day after payday. Download each account's transactions since the last time, import them, and give each one a category. Overlapping dates are fine: the rows you already have are recognized. For most people that's five minutes a week, and it's when you'll notice the subscription you forgot or the charge you don't recognize.
