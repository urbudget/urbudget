Installing takes a minute

No account, key or sign-in is needed to start budgeting.

Windows

From the Microsoft Store

  1. Choose Get it from the Microsoft Store, then Get on UrBudget's page in the Store.
  2. The Store downloads and installs it.
  3. Open UrBudget from the Start menu.

Windows

With the installer

  1. Open the .exe file you downloaded.
  2. If Windows says Windows protected your PC, choose More info, then Run anyway. You only do this once.
  3. Follow the installer. It installs for your user account, so it doesn't ask for an administrator password.

macOS

On a Mac

  1. Open the .dmg file you downloaded.
  2. Drag UrBudget into Applications.
  3. Open it from Applications. When macOS asks about an app downloaded from the internet, choose Open.

Questions about installing

Should I use the Microsoft Store or the installer?

The Store, if your computer has it: it installs in one step and updates through the Store. The installer is for computers without the Store, or if you'd rather not use it. It updates itself: UrBudget shows an Update button when there's a new version and installs it when you choose Install & restart.

Can I switch from one to the other?

Yes, but use one or the other, not both. Before you switch, export each budget (Settings → Backup & export → Export), because the Store version can keep its budgets in a separate folder. Then import them in the version you're keeping.

How do updates work?

UrBudget looks for a new version a few seconds after it starts and once a day. When there is one, an Update button appears in the title bar, and nothing installs until you choose Install & restart; your budget is saved first. The Microsoft Store version updates through the Store instead. Updates are included with the license.

Versions 1.0.0 and 1.0.1 don't look for updates. If you have one of them, download UrBudget again from this page and install it; your budgets stay as they are.

Where are my budgets stored?

In %APPDATA%\com.localbudget.desktop on Windows and ~/Library/Application Support/com.localbudget.desktop on macOS. Each budget is its own SQLite file, with its backups next to it.

The Microsoft Store version uses that folder too if the installer already made it. Otherwise Windows gives it a private one, %LOCALAPPDATA%\Packages\urbudget.UrBudget_s1gzxw095tb8a\LocalCache\Roaming\com.localbudget.desktop, which the installer version can't see.

What happens to my budgets if I uninstall?

Uninstalling the installer version keeps them, unless you tick Delete the application data. That deletes the folder, with every budget and backup in it, even if the Store version uses it too.

Uninstalling the Store version deletes its private folder, if it has one. Export each budget first (Settings → Backup & export → Export) if you might want it again.

Does UrBudget need an internet connection?

Not to budget. It goes online only to check for updates, for Sync, and for the optional assistant.

Is there a version for phones, tablets or Linux?

No. UrBudget is a desktop app for Windows 10 and 11 and for macOS 12 Monterey or later.

How can I check a download?

Compare its SHA-256 checksum with the one below. On Windows, in PowerShell: Get-FileHash "$env:USERPROFILE\Downloads\UrBudget_x64-setup.exe" On a Mac, in Terminal: shasum -a 256 ~/Downloads/UrBudget_universal.dmg
